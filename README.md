📌 **Project Overview**

This project focuses on analyzing Spotify music streaming data using SQL to uncover meaningful insights related to track performance, audience engagement, artist popularity, and platform trends.

The goal of this project is to perform structured data analysis on Spotify and YouTube metrics using SQL queries across multiple analytical levels.

This project demonstrates strong skills in:

- Data querying and aggregation
- Joins and subqueries
- CTEs and window functions
- Data-driven business analysis
- Analytical problem solving using SQL

---

🧩 **Business Problem**

The objective of this analysis is to help understand:

- Music streaming and engagement trends
- Artist and album performance
- Cross-platform audience behavior
- Popular audio characteristics of successful tracks
- Business insights that support content and marketing strategies

---
📊 **Business Questions Addressed**

🔹 **Core Streaming Insights**
- Retrieve tracks with more than 1 billion streams/
- List albums along with their respective artists/
- Calculate total comments for licensed tracks/
- Identify tracks released as singles/
- Count total tracks produced by each artist

🔹 **Engagement & Performance Analytics**
- Calculate average danceability for tracks in each album
- Find the top 5 tracks with the highest energy values
- Analyze official video performance using views and likes
- Calculate total album views across associated tracks
- Compare Spotify streams with YouTube streams

🔹 **Statistical & Ranking Analysis**
- Identify the top 3 most-viewed tracks for each artist using window functions
- Find tracks with above-average liveness scores
- Use CTEs to calculate energy variation within albums
---
📈 **Key Business Insights**
- Tracks with higher energy and danceability showed stronger audience engagement.
- Official videos significantly increased views and audience interaction.
- Singles consistently performed better in streaming popularity metrics.
- A small number of top-performing tracks contributed heavily to artist visibility.
- Listener behavior differed across Spotify and YouTube platforms.
